# PlantCare AI 🌱 (Plain HTML / CSS / JS)

**ذكي في رعاية نباتك — Smart care for your plant**
**فكرة وتصميم: سما مصطفى — Concept & design by Sama Mostafa**

A **frontend-only prototype** of a smart plant irrigation monitoring system — no build step, no
npm install, no backend. Just open `index.html` in a browser.

> ⚠️ This is a UI prototype only. There is **no backend, no database, no real ESP32/WiFi
> connection, and no real IoT communication**. All sensor readings are mock data generated by
> `js/app.js` in the browser.

## How to run it

Just double-click `index.html`, or open it from your browser with **File → Open**. That's it —
no terminal, no `npm install`, no server required.

(If your browser blocks local file access for some reason, you can also run a tiny local server,
e.g. `python3 -m http.server` from this folder, then visit `http://localhost:8000`.)

## What's inside

- `index.html` — all five screens (Home, Sensors, Environment, History, Settings)
- `css/style.css` — the whole visual design (light/dark themes, RTL/LTR, responsive layout for
  phone / tablet / desktop)
- `js/i18n.js` — Arabic + English text dictionary
- `js/water.js` — the simulated watering-amount calculator
- `js/app.js` — app state, mock sensor simulation, rendering, and all interactions

No frameworks, no bundler, no dependencies — plain HTML, CSS and JavaScript.

## Features

- **Dashboard**: plant status ("🌱 النبات يحتاج إلى الماء" / "لا يحتاج"), average soil moisture
  with a progress bar, a sensor overview grid.
- **Read sensors button**: shows a short loading state, nudges every sensor value, recalculates
  the average, and logs a new history point.
- **Sensor details**: the four soil sensors with their own progress bar and status (جافة / متوسطة / جيدة).
- **Environment**: temperature, air humidity and air pressure cards.
- **Estimated water amount**: appears automatically when the plant needs water. Shows current vs.
  target moisture and temperature, lets you pick a plant type and pot size, and calculates a
  *suggested* amount (e.g. "0.8 لتر") and timing — always labelled as an estimate, never an exact
  required amount, and no pump is ever controlled.
- **History**: a small bar chart of the last readings, showing the drying trend.
- **Device status**: a simulated "🟢 متصل / ESP32 / آخر قراءة: منذ ٣ ثواني" card.
- **Settings**: plant name, minimum moisture threshold (default 30%), target moisture (default
  35%), notifications toggle, dark mode, and Arabic/English language switch.
- Mobile-first with a bottom nav bar; a sidebar nav appears automatically on tablet/desktop widths.

## Notes

- Settings and sensor state are kept in memory only (a page refresh resets to the initial demo
  values) — the same behavior as the original React version of this prototype.
- Tested with a headless Chromium pass covering: initial state, "read sensors", the water
  calculator (including that no NaN ever appears), all five pages, dark mode, language switching,
  reset, and both the desktop sidebar and mobile bottom-nav layouts.
